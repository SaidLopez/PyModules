PyModules Full-Stack Demo

Commands → Module → EventBus → Outbound policy → SSE → this page.

1. Log in (dev shortcut)

Hits POST /__demo__/login which mints an HttpOnly access cookie for the chosen tenant. NOT for production — real apps integrate a proper IdP.

not logged in

2. Post a message

Hits POST /messages. The MessageModule handles the Command and publishes a MessagePosted Event. The Outbound policy gates delivery to the matching tenant only.

3. Live messages (SSE)

EventSource("/__pymodules__/events?subscribe=MessagePosted"). Only events for your tenant arrive here — the @outbound_policy on the server filters per connection.
